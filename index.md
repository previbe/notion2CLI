# notion2CLI

Use a Notion page as the rich-text input surface for a local Codex CLI or Claude Code session.

notion2CLI is a local-first Chrome extension and command-line bridge. It sends selected Notion text or a full Notion page to a local AI runtime, then shows the result back in the browser Activity panel.

## Chrome Extension

Install the extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/notion2cli/poadenkneikinepacildoepjamefghio). The Chrome extension connects to a local bridge at `http://127.0.0.1:43821`. notion2CLI does not operate a hosted backend for user Notion content.
