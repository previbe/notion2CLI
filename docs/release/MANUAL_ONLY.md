# Manual-Only Launch Tasks

These tasks require account ownership, payment, verification, or human product judgment.

## Chrome Web Store

- Wait for Google developer account approval.
- Complete Trader verification.
- Provide legal name, public contact email, phone, and public address as required by the dashboard.
- Upload the extension zip from `dist/chrome/`.
- Paste the listing, privacy, and reviewer materials.
- Provide a public privacy policy URL.
- Submit for review.
- Respond to reviewer questions.

## npm

- Confirm npm package name ownership.
- Run `npm login`.
- Complete 2FA.
- Run `npm publish --access public`.

## GitHub

- Confirm the release tag and release body.
- Publish the GitHub Release if browser auth or repository permissions are required.

## Product Hunt

- Use a personal Product Hunt account.
- Complete account onboarding.
- Choose launch date.
- Upload final gallery images and thumbnail.
- Publish or schedule the launch.

## Legal And Brand

- Final legal review of privacy policy and public trader details.
- Decide whether the project is released under an individual name, company, or publisher brand.
- Provide final support email.
- Provide final website / privacy policy URL.

## Real Product Validation

- Run a real Notion page test with Codex.
- Run a real Notion page test with Claude.
- Verify manual write-back on a non-sensitive test page.
- Verify Chrome Web Store installation once approved.
