## Design Context

### Users
This tool is for developers and technical operators who already work in Notion in the browser and keep Claude Code open locally. Their job is to trigger a repeatable Claude workflow from the current Notion page without copy-pasting back and forth.

### Brand Personality
Calm, trustworthy, sharp. The interface should feel like a small local utility that is dependable rather than flashy.

### Aesthetic Direction
Light-first, editorial utility. Warm paper-like neutrals, dark ink text, and one restrained moss accent. The UI should look intentional and native to a productivity workflow, not like a generic AI dashboard.

### Design Principles
1. The primary action should always be obvious from inside Notion.
2. System state must be legible in plain language: disconnected, ready, running, failed, completed.
3. Keep the user in the browser unless Claude genuinely needs manual intervention.
4. Prefer confidence and clarity over visual novelty.
5. Use progressive disclosure: one obvious button first, details only when needed.
